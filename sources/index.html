CALB L148N58A comprehensive characterization study

Paper: A dataset for large prismatic lithium-ion battery cells (CALB L148N58A): Comprehensive characterization and real-world driving cycles. Dataset: CALB L148N58A testing campaign. DOI: 10.17632/ycx459r5c3.2.

This project did pulse-to-EIS analysis on selected CALB outputs. It does not prove external validation.

Open CALB source dataset

LG M50T 21700 degradation study, Expt 4 drive-cycle aging

Paper: Lithium-ion battery degradation: Comprehensive cycle ageing data and analysis for commercial 21700 cells. Dataset DOI: 10.5281/zenodo.10637534. Subset: Expt 4 - Drive Cycle Aging (Control).

This project did drive-cycle ageing health-feature analysis. It does not prove EIS-validated DRT evidence.

Open LG M50T source dataset
