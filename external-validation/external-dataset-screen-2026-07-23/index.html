Five external datasets, one matching rule

A compact screening pass to find which public sources can support a same-cell link between time-series cycling data, EIS, and later DRT analysis.

Read this first

What was actually checked?

  • NASA, CALCE, and Cambridge use local manifest summaries already present in this repository.
  • Battery Archive and the 54-cell Zenodo set are online metadata screens; their raw files were not treated as downloaded.
  • The score is dataset readiness for our pipeline, not model accuracy and not validation.

Decision

Best next test

  • Use Cambridge as the first full TS + EIS holdout because the local inspection shows same-cell GCPL and GEIS records.
  • Use NASA and CALCE as robustness checks for different cell IDs, temperatures, storage conditions, and impedance formats.
  • Use the 54-cell Zenodo set as an EIS/DRT control, not as a TS-to-EIS bridge.
  • Do not rank Battery Archive higher until a requested CSV confirms same-cell impedance coverage.
