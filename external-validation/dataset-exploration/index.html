Panasonic, Samsung, and Graphite/LNMO Dataset Exploration

A presentation-style readout for three newly downloaded battery datasets. It explains what each dataset contains, what was plotted, what can be tested, and what cannot honestly be claimed.

How To Read This Page

The frozen CALB pulse-to-EIS rule is the internal rule previously labeled frozen pulse-to-EIS rule. In simple terms, it asks whether a current/voltage pulse can recover impedance-like information that agrees with EIS, which means Electrochemical Impedance Spectroscopy.

A dataset is useful for that test only if it has both sides of the bridge: same-cell EIS spectra and matching time-domain pulse or rest windows with current, voltage, temperature, and state labels. More files do not automatically mean better validation. A huge pulse dataset without EIS still cannot validate this rule.

Frozen inputs means the rule is not allowed to change after seeing the external data. No tuning lambda, thresholds, windows, candidate rules, fallback logic, or pass criteria. That is the whole point. If we tune after looking, we are fooling ourselves.

Bottom Line

Panasonic was the only dataset here that deserved a real frozen-rule test workflow attempt. That attempt has now run. The result is not supportive: 3 test workflow joins, 33 rule rows, 0 quality-pass rows, and the fixed rule did not beat the voltage-only baseline.

Samsung is useful for pulse-only exploration because it has large HPPC-style time-series archives. But no same-cell EIS was observed locally, so Samsung cannot validate the frozen pulse-to-EIS rule by itself.

Graphite/LNMO has clean EIS and useful electrochemical protocols, but it does not line up cleanly with the frozen pulse-to-EIS gate. The qOCV file gives zero accepted candidates, and the rate file gives only one long candidate.

None of the three is aging validation. Panasonic tested the pulse-to-EIS bridge on a different cell format and chemistry context, and the result was no support. That is not a disaster. It is information. But pretending it is validation would be bad science.

Panasonic 18650PF

The Panasonic archive has both EIS CSV files and MATLAB pulse files across five temperatures. That matters because the frozen pulse-to-EIS rule needs both an impedance spectrum and a time-domain current/voltage response.

The true five-pulse HPPC files are too short for the frozen window rule because they are about 10 seconds long. The separate dis5_10p files are the important ones. Several of them contain long discharge windows with enough rest afterward to pass the frozen window gate.

Samsung INR21700-50E HPPC

The Samsung download is a large set of 7z archives with giant CSV reports. A streamed sample from Batch 1 shows usable current, voltage, cell temperature, and chamber temperature. That is good for pulse analysis.

The blocker is simple: no same-cell EIS was observed in the local files. Without EIS, there is nothing for the frozen pulse-to-EIS rule to compare the time-domain pulse result against. So Samsung is not a validation dataset for this rule unless a matching EIS source is found.

Graphite/LNMO

The graphite/LNMO archive is scientifically interesting, but weaker for this specific validation question. It has full-cell EIS by SOC, qOCV, rate, GITT-style files, and parameter JSONs. That is a rich electrochemistry package, but richness is not the same as frozen-rule readiness.

The frozen window finder sees zero candidates in qOCV because the current is below the hard rest threshold. It sees one long candidate in the rate file, but that is not a clean HPPC-style EIS-pulse check-up join. So this dataset is useful for presentation and side experiments, not an honest external run for the fixed CALB rule.

Next Move

The Panasonic test workflow already ran, so do not describe Panasonic as the next target anymore. The current frozen-rule verdict is no support.

The next useful move is not to tune the failed rule. The next useful move is to use the cross-dataset supervised early workflow on another dataset that has same-cell EIS plus earlier current/voltage time series, then freeze the model and baseline before scoring it once.
