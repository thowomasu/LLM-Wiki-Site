Evidence words used on this site

These words describe how trustworthy a result is. They do not describe whether the software ran.

Internal resultA result from the same dataset family used to build the method. It is useful for development, but it is not independent proof.
Held-out-cell foldOne repeated check where a whole cell is left out of training, tested, then replaced by another left-out cell.
External testA test on a different dataset that was not used to build or choose the method.
UntouchedThe final answers for those cells were not used to choose features, models, limits, or pass rules before scoring.
Frozen or lockedThe inputs, model, baseline, and pass rules were fixed before the outside answers were viewed.
Freeze-readyThe method was complete and stable enough to lock before spending a new outside dataset. It does not mean the method had already passed externally.
PassedThe result met every rule fixed in advance.
FailedThe result missed at least one rule fixed in advance. It does not mean the code crashed.

Start here: what Version 5 fixed

Version 4 could predict EIS, but its health model still needed the real current EIS measurement. Version 5 removed that shortcut. It first predicts the missing EIS, then feeds only that prediction into the health model.

Fresh referenceStore the cell's earlier EIS and pulse resistance.
Later pulseMeasure how pulse resistance changed as the cell aged.
Predict missing EISEstimate the current spectrum without measuring it.
Predict healthUse predicted EIS, not measured current EIS, to estimate SOH.
SOHState of health, defined here from remaining capacity relative to the fresh cell.
Chained modelThe output of the EIS model becomes an input to the health model.
Domain guardA safety check that rejects an input when it is too different from development data.
AbstainReturn no prediction because the input is outside the model's allowed domain.

Why zero accepted SiCWell rows is a failure

The guard behaved like a locked door. Every SiCWell input was too far from the Leonardi development domain, so no external prediction was allowed. That is safer than guessing, but it means the method provided no usable external result.

Do not misread the result:

Zero accepted rows does not mean zero prediction error. It means the frozen method could not operate on the external dataset at all.

Executive Read

Version 5 fixed V4's biggest architecture gap. The health model was trained on EIS predicted without access to the held cell, so the deployed chain could estimate SOH when current EIS was missing.

What the model sees

Fresh same-cell EIS, SOC, and matched pulse-resistance change. Current EIS is optional, not required for the chain.

What it predicts

Real EIS, negative-imaginary EIS, chained SOH, 90% residual intervals, domain distance, and an abstention reason.

What worked

All four output models passed eight repeated checks. In each check, one whole Leonardi cell was left out of training and used only for testing.

What failed

The frozen guard rejected every one of 892 SiCWell rows. Therefore V5 has no external support.

Verdict:

external_validation_failed. This is not a near pass and the guard must not be widened after seeing SiCWell.

Complete missing-EIS pipeline

1. Reference dataFresh same-cell, same-SOC EIS plus a fresh pulse resistance.
2. Current pulseThe current matched pulse gives relative resistance increase.
3. Predict current EISSeparate real and imaginary Extra Trees heads reconstruct the nine-point spectrum.
4. Build chain featuresNormalize predicted EIS and combine it with the baseline spectral shape.
5. Predict SOHThe chain head outputs capacity-based SOH without measured current EIS.
6. Guard and intervalAbstain outside the frozen development domain and attach 90% residual ranges.

The optional direct head uses measured current EIS only as a diagnostic upper comparison. It is not the missing-measurement solution.

Math

1. EIS reconstruction, inherited from V4
\[\widehat{Z}_k = B_k + s\,f_k(x),\qquad s=\sqrt{B_{\mathrm{re},1}^2+B_{-\mathrm{im},1}^2}\]
2. Direct and chained health heads
\[\widehat{h}_{\mathrm{direct}}=g\!\left(\Delta R_{\mathrm{int}}, Z/s, B/s\right),\qquad \widehat{h}_{\mathrm{chain}}=g_{c}\!\left(\Delta R_{\mathrm{int}}, \widehat{Z}/s, B/s\right)\]

The key distinction is Z versus predicted Z. The chained model is trained on out-of-cell predictions, not cleaned-up measured EIS.

3. Development-calibrated residual interval
\[q_{0.90}=Q_{0.90}\!\left(\left|y_i-\widehat{y}_i\right|\right),\qquad \mathcal{I}(x)=\left[\widehat{y}(x)-q_{0.90},\widehat{y}(x)+q_{0.90}\right]\]
4. Applicability distance
\[d(x)=\min_{i\in\mathrm{development}}\left\|T(x)-T(x_i)\right\|_2,\qquad \mathrm{accept}(x)\iff d(x)\le Q_{0.95}(d_{\mathrm{LOCO}})\]

T is median imputation plus standardization fitted on development data. The frozen threshold is 0.405903.

Nested leave-one-cell-out training

Outer held cellOne of eight Leonardi cells is absent from every model fit used to score it.
Inner cross-fittingTraining-cell EIS is predicted by models that did not see that training cell.
Chain trainingThe SOH head learns from those out-of-cell EIS predictions.
Outer scoreThe EIS heads and chained SOH head score the untouched outer cell.
EstimatorExtra Trees, 300 trees, depth 8, minimum leaf size 2, random seed 19.
PreprocessingMedian imputation and StandardScaler in a fixed pipeline.
EIS baselineFresh same-cell spectrum carried forward.
SOH baselineConstant 100% SOH.

Evidence boundary:

These are strong checks within the Leonardi dataset family. They were good enough to lock the method and justify one new outside-data test, but they are not independent outside proof.

Limits and failure meaning

  • The V5 architecture is complete, but it is supported only by same-dataset Leonardi development results.
  • The frozen SiCWell guard failure means the intended external domain was not covered.
  • Widening the guard now would spend the kept-back test again and invalidate the one-shot test.
  • SiCWell may be used for protocol diagnosis and later development, never relabeled as V5 validation.
Correct claim:

V5 is the strongest complete internal chain in this family, with external validation failed and no external support.
