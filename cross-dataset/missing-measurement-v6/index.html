Evidence words used on this site

These words describe how trustworthy a result is. They do not describe whether the software ran.

Internal resultA result from the same dataset family used to build the method. It is useful for development, but it is not independent proof.
Held-out-cell foldOne repeated check where a whole cell is left out of training, tested, then replaced by another left-out cell.
External testA test on a different dataset that was not used to build or choose the method.
UntouchedThe final answers for those cells were not used to choose features, models, limits, or pass rules before scoring.
Frozen or lockedThe inputs, model, baseline, and pass rules were fixed before the outside answers were viewed.
Freeze-readyThe method was complete and stable enough to lock before spending a new outside dataset. It does not mean the method had already passed externally.
PassedThe result met every rule fixed in advance.
FailedThe result missed at least one rule fixed in advance. It does not mean the code crashed.

Start here: why Version 6 exists

By Version 6, the project had seen strong results inside one dataset and weak results when moving between datasets. Version 6 tested several possible rescue ideas using only datasets that were already spent. It did not open another untouched external dataset.

Zero-shotTrain on some datasets and predict a new dataset without using any of its labelled cells.
Few-shot calibrationUse one or two labelled cells from the target dataset, then test on different target cells.
RepresentationThe fixed numerical form given to a model, such as scale-normalized changes or frequency ratios.
Dataset-level testHold back an entire dataset. This is harder and more informative than holding back rows from the same dataset.

The tests in one sentence each

  • Zero-shot: can a model trained elsewhere work with no target labels?
  • Few-shot: can one or two calibration cells repair the transfer problem?
  • Guard: can the model reject unfamiliar and unsafe inputs?
  • Uncertainty: do the claimed 90% ranges actually contain about 90% of the true values?
Answer:

No tested combination passed all required dataset-level gates. Version 6 therefore ended the universal-model path instead of manufacturing another candidate.

Executive Read

Version 6 was a bounded development study, not a new external-validation attempt. It tested whether representation changes, whole-dataset transfer, small target-cell calibration, applicability guards, or uncertainty estimates could produce a candidate worth freezing.

Evidence used

1383 rows from 51 cells across four datasets that were already inspected or scored.

Models compared

Ridge and Extra Trees across the V5 reference plus four portable representations. Physical summaries failed closed before scoring.

Evaluation hierarchy

Leave one whole dataset out was primary. Held-cell tests inside a dataset were secondary only.

Outcome

No zero-shot or fixed-budget calibration candidate passed every predictive, retention, and uncertainty gate.

Decision:

stop_universal_model_path. No V6 model was frozen and no new V6 kept-back test search is authorized.

Research question

Can one portable missing-measurement model transfer across exact-cell, chemistry, protocol, temperature, and instrument changes with either zero target labels or a very small, fixed calibration budget?

Blunt standard:

A model could not advance because one dataset looked good. Every required predictive head had to meet median, worst-dataset, multi-dataset, guard, and uncertainty rules.

Math and model families

1. Ridge reference model
\[\widehat{W}=\arg\min_W \left\|Y-XW\right\|_F^2+\alpha\left\|W\right\|_F^2\]

Ridge is the simple linear model. Extra Trees is the nonlinear comparison using randomized decision trees. Both receive the same fixed representation inside a fold.

2. Dimensionless spectral change
\[r_k=\frac{Z_k}{B_k},\qquad \delta_k=\frac{Z_k-B_k}{s}\]
3. Dataset-level relative improvement
\[I_{d,h}=\frac{E_{d,h}^{\mathrm{best\ baseline}}-E_{d,h}^{\mathrm{model}}}{E_{d,h}^{\mathrm{best\ baseline}}}\]

The candidate screen uses the median and worst dataset value for every head h, not pooled rows across all datasets.

4. Few-shot residual and affine adaptation
\[\widehat{y}_{\mathrm{res}}(x)=\widehat{y}_0(x)+\frac1m\sum_{j\in C}\left(y_j-\widehat{y}_0(x_j)\right),\qquad \widehat{y}_{\mathrm{aff}}(x)=a\widehat{y}_0(x)+b\]

C contains calibration-only cells. Evaluation cells never enter the calibration fit.

5. Source-only guard and uncertainty
\[d(x)=\min_i\|T(x)-T(x_i)\|_2,\quad d(x)\le Q_{0.95}(d_{\mathrm{source}}),\quad \mathcal{I}(x)=\widehat{y}(x)\pm Q_{0.90}(|e_{\mathrm{source}}|)\]

Hard decision

Freeze zero shot?No candidate passed every zero-shot gate.
Narrow to few shot?No disjoint-cell budget passed baseline, zero-shot improvement, and multi-dataset gates.
Validate V6?No. There is no frozen candidate to validate.
Next pathA new exact-cell controlled-measurement study, not V7.
  • Do not widen V5 thresholds or rescore SiCWell as validation.
  • Do not authorize a fresh V6 kept-back test search.
  • Do not use strong repeated held-cell checks within Leonardi to soften weak transfer between whole datasets.
  • Do not claim that every narrow chemistry-specific model is impossible.
