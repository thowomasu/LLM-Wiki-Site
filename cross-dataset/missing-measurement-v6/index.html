Version 6: Universal Transfer Decision Study

A self-contained technical account of the four-dataset matrix, description of the measurementss, model math, without target-dataset calibration and with one or two target cells for calibration tests, guards, uncertainty, and stop decision.

Start here: why Version 6 exists

By Version 6, the project had seen strong results inside one dataset and weak results when moving between datasets. Version 6 tested several possible rescue ideas using only datasets that were already spent. It did not open another untouched external dataset.

Zero-shotTrain on some datasets and predict a new dataset without using any of its labelled cells.
Few-shot calibrationUse one or two labelled cells from the target dataset, then test on different target cells.
RepresentationThe fixed numerical form given to a model, such as scale-normalized changes or frequency ratios.
Dataset-level testHold back an entire dataset. This is harder and more informative than holding back rows from the same dataset.

The tests in one sentence each

  • Zero-shot: can a model trained elsewhere work with no target labels?
  • Few-shot: can one or two calibration cells repair the transfer problem?
  • Guard: can the model reject unfamiliar and unsafe inputs?
  • Uncertainty: do the claimed 90% ranges actually contain about 90% of the true values?
Answer:

No tested combination passed all required dataset-level gates. Version 6 therefore ended the universal-model path instead of manufacturing another candidate.

Executive Read

Version 6 was a bounded development study, not a new external-validation attempt. It tested whether description of the measurements changes, whole-dataset transfer, small target-cell calibration, safety checks, or uncertainty estimates could produce a candidate worth freezing.

Evidence used

1383 rows from 51 cells across four datasets that were already inspected or scored.

Models compared

Ridge and Extra Trees across the V5 reference plus four portable description of the measurementss. Physical summaries failed closed before scoring.

Evaluation hierarchy

Leave one whole dataset out was primary. Held-cell tests inside a dataset were secondary only.

Outcome

No without target-dataset calibration or fixed-budget calibration candidate passed every predictive, retention, and uncertainty gate.

Decision:

stop_universal_model_path. No V6 model was frozen and no new V6 kept-back test search is authorized.

Research question

Can one portable missing-measurement model transfer across exact-cell, chemistry, protocol, temperature, and instrument changes with either zero target labels or a very small, fixed calibration budget?

Blunt standard:

A model could not advance because one dataset looked good. Every required predictive head had to meet median, worst-dataset, multi-dataset, guard, and uncertainty rules.

What Version 6 promised to test before scoring

Why this section exists:

Version 5 failed when it moved to a different dataset. Version 6 therefore wrote down several possible ways to express the same battery measurements, the models to compare, the data splits, and the pass rules before reading the Version 6 scores. This prevents us from seeing the answers first and then presenting whichever setup happened to look best.

The five scored description of the measurementss below are not five different datasets or five final models. They are five fixed ways of turning the same available measurements into model inputs. Each one asks a specific transfer question.

Version 5 referenceCode name: v5_reference. This is the unchanged V5 input design. It is the control that tells us whether a new description of the measurements actually improves on V5.
Separate scale and shapeCode name: scale_shape. It asks whether transfer improves when overall impedance size is kept separate from the curve's normalized shape and change.
Use changes without physical unitsCode name: dimensionless_change. It asks whether ratios and scale-normalized changes transfer better across cell sizes, protocols, and instruments.
Use fewer frequency featuresCode name: reduced_frequency. It asks whether fixed low-, middle-, and high-frequency summaries are less fragile than the full spectrum.
Use one small mixed feature setCode name: hybrid_small. It keeps SOC, temperature, pulse change, impedance scale, and a compact shape summary while removing many detailed spectrum features.
Physical summary, stopped before scoringCode name: physical_summary. This option needed repeatability, instrument, amplitude, and temperature metadata that the datasets did not consistently provide. The study excluded it instead of inventing unreliable physical features.

How the comparisons were kept fair

Primary questionTrain on three datasets and test on the complete fourth dataset. Repeat until every dataset has been held back once.
Secondary questionLeave one cell out inside a dataset. This checks same-dataset cell transfer, not outside-dataset transfer.
Zero-shot budgetUse no labels, statistics, or normalization fitted from the held-back dataset.
Few-shot budgetUse one or two named calibration cells, then evaluate on different cells from that dataset.

What “predeclared” means here: these choices were fixed before their candidate scores were judged. It does not mean Version 6 was externally validated. All four datasets had already been inspected in earlier work, so Version 6 remained a development study.

Math and model families

1. Ridge reference model
\[\widehat{W}=\arg\min_W \left\|Y-XW\right\|_F^2+\alpha\left\|W\right\|_F^2\]
WYXalpha

Ridge is the simple linear model. Extra Trees is the nonlinear comparison using randomized decision trees. Both receive the same fixed description of the measurements inside a fold.

2. Dimensionless spectral change
\[r_k=\frac{Z_k}{B_k},\qquad \delta_k=\frac{Z_k-B_k}{s}\]
r_kZ_kB_kdelta_ks
3. Dataset-level relative improvement
\[I_{d,h}=\frac{E_{d,h}^{\mathrm{best\ baseline}}-E_{d,h}^{\mathrm{model}}}{E_{d,h}^{\mathrm{best\ baseline}}}\]
I_d,hE_baselineE_model

The candidate screen uses the median and worst dataset value for every head h, not pooled rows across all datasets.

4. Few-shot residual and affine adaptation
\[\widehat{y}_{\mathrm{res}}(x)=\widehat{y}_0(x)+\frac1m\sum_{j\in C}\left(y_j-\widehat{y}_0(x_j)\right),\qquad \widehat{y}_{\mathrm{aff}}(x)=a\widehat{y}_0(x)+b\]
Cma, b

C contains calibration-only cells. Evaluation cells never enter the calibration fit.

5. Source-only guard and uncertainty
\[d(x)=\min_i\|T(x)-T(x_i)\|_2,\quad d(x)\le Q_{0.95}(d_{\mathrm{source}}),\quad \mathcal{I}(x)=\widehat{y}(x)\pm Q_{0.90}(|e_{\mathrm{source}}|)\]
d(x)T(x)

Hard decision

Freeze zero shot?No candidate passed every without target-dataset calibration gate.
Narrow to few shot?No disjoint-cell budget passed baseline, without target-dataset calibration improvement, and multi-dataset gates.
Validate V6?No. There is no frozen candidate to validate.
Next pathA new exact-cell controlled-measurement study, not V7.
  • Do not widen V5 thresholds or rescore SiCWell as validation.
  • Do not authorize a fresh V6 kept-back test search.
  • Do not use strong repeated held-cell checks within Leonardi to soften weak transfer between whole datasets.
  • Do not claim that every narrow chemistry-specific model is impossible.
