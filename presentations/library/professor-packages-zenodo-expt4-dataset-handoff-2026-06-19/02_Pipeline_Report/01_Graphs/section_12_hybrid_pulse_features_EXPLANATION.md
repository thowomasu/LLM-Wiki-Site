# Graph Explanation: multi-cell 2D batch check Hybrid Pulse Features

Graph file: `section_12_hybrid_pulse_features.png`

## What This Figure Shows

This graph summarizes dynamic-response features from the hybrid CC-pulse files.

## How To Read It

P95 current, voltage span, and transition count describe how hard the trace excites the cell and how much response is visible.

## What We Can Learn

Hybrid pulse files add another protocol view of ageing. They may become a richer dynamic-response track than plain discharge curves.

## Caveat

The current pipeline does not call these hybrid features DRT. That would require stricter pulse/rest segmentation and validation.
