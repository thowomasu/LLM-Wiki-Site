# Graph Explanation: EIS DRT baseline Gitt Batch Summary

Graph file: `section_5_gitt_batch_summary.png`

## What This Figure Shows

This graph summarizes GITT fits across multiple LG M50T 21700 Expt 4 drive-cycle aging cells and RPT points.

## How To Read It

RMSE shows voltage-fit quality. R0 shows the immediate resistance estimate. Main peak tau shows where the largest recovered relaxation feature lands.

## What We Can Learn

The pipeline scales beyond one file and produces comparable metrics across cells/RPTs.

## Caveat

Batch success is engineering evidence. It is not validation that time-domain DRT matches EIS.
