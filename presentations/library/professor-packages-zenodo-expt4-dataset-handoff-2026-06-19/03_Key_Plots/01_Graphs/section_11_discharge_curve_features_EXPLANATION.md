# Graph Explanation: time-series versus EIS 2D comparison Discharge Curve Features

Graph file: `section_11_discharge_curve_features.png`

## What This Figure Shows

This graph summarizes 0.1C and 0.5C discharge-curve features across cells and RPT points.

## How To Read It

Capacity proxy, mid-capacity voltage, and temperature rise are health features. They tell you how the cell behaves during controlled discharge as it ages.

## What We Can Learn

The Zenodo package contains useful non-GITT ageing evidence. Ignoring these files would leave real signal on the floor.

## Caveat

These traces are not DRT inputs. They support health-feature validation, not relaxation-spectrum physics.
