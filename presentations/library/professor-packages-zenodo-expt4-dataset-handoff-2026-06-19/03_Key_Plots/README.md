# Key Plots

The plots are in `01_Graphs/`.
Most plots have a matching `*_EXPLANATION.md` file.

## Recommended Read Order

| Plot | Why open it |
|---|---|
| `section_1_data_audit.png` | Confirms what files and families were found. |
| `section_3_gitt_window_plot.png` | Shows the selected GITT pulse window. |
| `section_4_gitt_candidate_fit_plot.png` | Shows the DRT-like fit on one candidate window. |
| `section_5_gitt_batch_summary.png` | Shows batch-level GITT fitting behavior. |
| `section_6_model_sensitivity.png` | Shows how sensitive peaks are to settings. |
| `section_8_health_label_join.png` | Shows feature-label relationships. |
| `section_9_held_out_cell_validation.png` | Shows internal validation performance. |
| `section_13_multi_protocol_validation.png` | Shows multi-protocol comparison. |

## Warning

Plots are good for orientation.
They are not proof.
For the strength of the claim, use the validation audit.
