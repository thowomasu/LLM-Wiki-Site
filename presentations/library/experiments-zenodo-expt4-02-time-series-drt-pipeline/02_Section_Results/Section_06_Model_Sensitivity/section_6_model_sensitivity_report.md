# LG M50T 21700 Expt 4 drive-cycle aging Time-Series DRT Pipeline, time-domain versus EIS bridge comparison

## Purpose

This section checks whether the GITT DRT result moves when baseline mode and lambda change.

## Interpretation

If peak tau or band mass moves a lot across settings, do not overclaim the DRT shape.
