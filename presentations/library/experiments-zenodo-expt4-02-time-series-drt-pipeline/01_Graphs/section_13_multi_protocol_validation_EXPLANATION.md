# Graph Explanation: multi-temperature 2D batch check Multi Protocol Validation

Graph file: `section_13_multi_protocol_validation.png`

## What This Figure Shows

This graph compares leave-one-cell-out health-label skill for discharge-only, hybrid-only, GITT-only, and combined feature sets.

## How To Read It

Bars above zero beat the train-mean baseline. Bars below zero are worse than a dumb baseline and should not be dressed up as success.

## What We Can Learn

This is the viability test for using the full Zenodo processed package instead of only GITT.

## Caveat

This is still internal health-label validation. It is not EIS-derived DRT validation.
