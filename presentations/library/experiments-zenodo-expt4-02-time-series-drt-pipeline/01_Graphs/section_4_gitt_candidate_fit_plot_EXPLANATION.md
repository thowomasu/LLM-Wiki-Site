# Graph Explanation: HPPC candidate fit Gitt Candidate Fit Plot

Graph file: `section_4_gitt_candidate_fit_plot.png`

## What This Figure Shows

This graph shows the fitted time-domain DRT model on one selected LG M50T 21700 Expt 4 drive-cycle aging GITT pulse/rest window.

## How To Read It

Start with voltage reconstruction and residual. If the fit misses voltage, the DRT curve is not worth interpreting. Then inspect the DRT panel as a model-derived distribution of relaxation weight over tau.

## What We Can Learn

The selected GITT window fits cleanly, so the pipeline can run on LG M50T 21700 Expt 4 drive-cycle aging data. The recovered peaks are features for comparison across files, not proof of physical truth.

## Caveat

This is not EIS validation. A low voltage RMSE can still hide model sensitivity in gamma.
