Public Research Briefs

Major HTML deliverables grouped by source study, dataset, and claim boundary.

Purpose: this is the public reading shelf for the project. It is written for an external technical reader who understands batteries, EIS, DRT, and validation basics, but does not have the private repo open. Each row tells you what the page is, which dataset it belongs to, what question it answers, where the public artifact came from, and where to open it.

Rashid and Faraji-Niri DIB battery SOH estimation dataset: time-domain DRT method pilot

Source identity: Mendeley dataset DIB_Data and the Data in Brief article Dataset for rapid state of health estimation of lithium batteries using EIS and machine learning: Training and validation. Dataset DOI: 10.17632/mn9fb7xdx6.3. Related EIS and machine-learning paper DOI: 10.1016/j.est.2022.106295. This project used the dataset as a method-development check. It does not validate CALB, LG M50T Expt 4, or any external frozen rule.
