Rashid and Faraji-Niri DIB battery SOH estimation dataset: time-domain DRT method pilot

Source identity: Mendeley dataset Rashid and Faraji-Niri DIB battery SOH estimation dataset and the Data in Brief article Dataset for rapid state of health estimation of lithium batteries using EIS and machine learning: Training and validation. Dataset DOI: 10.17632/mn9fb7xdx6.3. Related EIS and machine-learning paper DOI: 10.1016/j.est.2022.106295. This project used the dataset as a method-development check. It does not validate CALB, LG M50T Expt 4, or any external fixed rule.
