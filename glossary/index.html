Glossary

Plain definitions for battery, DRT, EIS, dataset, and validation terms used across the research site.

One glossary for the whole site: this table contains battery terms, evidence language, code names, and equation variables. Words with a dotted underline use these same definitions when you hover, focus, or tap them.
Term, code, or variablePlain name or reason for the nameWhat it means or does here
a, bAffine calibration slope and offsetTwo fitted numbers that rescale and shift a zero-shot prediction using calibration cells only.
AbstainRefuse to make an unsafe predictionThe model gives no prediction because the input is outside its safe or supported range.
alphaRidge penalty strengthControls how strongly large model weights are discouraged.
BB means the fresh baseline spectrumThe measured EIS spectrum from the same cell while it was fresh.
B_kB at frequency index kThe fresh baseline impedance value at one frequency point k.
BaselineSimple comparison predictionThe more complicated model must beat this under the rules fixed before final scoring.
CCalibration-cell setOnly the fixed target cells allowed for few-shot adjustment. Evaluation cells are excluded.
CALBChina Aviation Lithium BatteryManufacturer name used for the CALB L148N58A prismatic cell dataset.
CALCECenter for Advanced Life Cycle EngineeringExternal battery-data source used for candidate validation planning.
Chained modelOne prediction feeds another modelThe predicted EIS becomes an input to the SOH model, so EIS does not need to be measured at prediction time.
Cross-fittingBuild training predictions without self-exposureEach training cell receives an EIS prediction from a model that did not train on that cell before the health model is fitted.
d(x)Distance from x to known development dataThe nearest-source distance used by the applicability guard.
Dataset-level testHold back one complete datasetThe model learns from other datasets and is tested on a dataset it did not use for training.
delta_kScale-normalized change at frequency kThe difference Z_k minus B_k divided by the reference scale s.
delta_R_intRelative change in internal pulse resistanceThe percentage increase from the fresh pulse resistance to the current pulse resistance.
delta_z_kDelta means change, so this is normalized impedance change at kThe difference between current and fresh impedance at frequency k, divided by s.
DIBData in BriefJournal style. Do not use it as the public name for the LG M50T Expt 4 dataset.
Dimensionless changeRelative change without physical unitsCurrent impedance is divided by or scaled against the fresh reference so different absolute sizes are easier to compare.
dimensionless_changeWhy the name: ratios remove physical unitsWhat it does: expresses each current spectrum value as a ratio or scale-normalized change from the fresh reference.
Domain guardInput safety checkA rule that rejects data that are too different from the data the model knows.
DRTDistribution of Relaxation TimesBattery-analysis method that represents relaxation behavior across time constants.
E_baselineBaseline prediction errorThe RMSE or MAE produced by the simple comparison method.
E_modelModel prediction errorThe RMSE or MAE produced by the tested model.
ECMEquivalent Circuit ModelCompact battery model used as a baseline in drive-cycle audits.
EISElectrochemical Impedance SpectroscopyFrequency-domain impedance test used as the comparison target for DRT outputs.
External testTest on a different datasetThe outside dataset was not used to build or choose the method.
Extra TreesExtremely Randomized TreesA nonlinear ensemble that averages many randomized decision trees.
f_kf means the learned EIS prediction function at kThe model that predicts normalized impedance change at one frequency point.
FailedMissed at least one rule fixed in advanceThis describes the evidence result. It does not mean the code crashed.
Few-shot calibrationSmall target-data adjustmentA small number of labelled cells or check-ups from the new dataset are used to adjust the model before evaluation.
Freeze-readyComplete enough to lock for a new outside testThis does not mean the method has passed externally. It means the method is ready to be tested without changing its rules.
Frequency gridFixed list of EIS frequenciesThe exact frequency points where impedance values are aligned, predicted, and compared.
Frozen or lockedRules fixed before outside answersInputs, preprocessing, models, baselines, and pass rules cannot be changed after the outside answers are viewed.
h_chainChained health predictionSOH predicted from reconstructed EIS, without using measured current EIS at prediction time.
h_directDirect health predictionSOH predicted using measured current EIS. It is a diagnostic upper comparison, not the missing-EIS solution.
Held-out-cell foldOne repeated whole-cell checkOne cell is left out of training and tested. The process repeats with different cells left out.
HPPCHybrid Pulse Power CharacterizationPulse protocol used to extract time-domain relaxation windows.
Hybrid smallSmall mixed feature setA compact representation combining SOC, temperature, pulse change, impedance scale, and a short shape summary.
hybrid_smallWhy the name: it mixes several signal types in a small feature setWhat it does: combines SOC, temperature, pulse change, scale, and a compact spectral-shape summary.
II means relative improvementThe fraction by which model error is lower than baseline error. Positive is better.
I_d,hImprovement for dataset d and output head hThe relative error improvement is calculated separately for each dataset and prediction target.
Internal resultResult from the development dataset familyUseful evidence for building the method, but not independent proof that it works elsewhere.
KKKramers-KronigEIS consistency screen. In this project it is a quality gate, not a model feature.
L148N58A58 Ah large prismatic lithium-ion cell modelThe specific cell model in the CALB paper and Mendeley repository.
Leave-one-dataset-outWhole-dataset transfer checkThe model learns from all but one dataset, then the missing dataset is used as a separate test.
LG M50TCommercial 21700 cylindrical lithium-ion cellCell family in the degradation study where this project used Expt 4 drive-cycle ageing data.
LLMLarge Language ModelThe AI tooling layer used to maintain this research wiki and generate public-facing outputs.
mNumber of calibration examplesThe count used when averaging calibration residuals.
MAEMean Absolute ErrorThe average absolute prediction mistake. Lower is better.
NASANational Aeronautics and Space AdministrationExternal battery dataset source considered after CALCE and corrected-EIS RADAR4KIT.
NormalizationRescale values before modelingValues are put on a comparable scale so a large cell or instrument range does not dominate only because its numbers are bigger.
OCVOpen Circuit VoltageRested voltage used to match pulse candidates with EIS records.
PassedMet every rule fixed in advanceThe scored result met every required pass rule. It does not automatically prove that the method works everywhere.
Physical summaryCompact physically motivated featuresA planned representation that was excluded because the repeatability, instrument, amplitude, and temperature metadata needed to build it safely were missing.
physical_summaryWhy the name: it was meant to summarize physically meaningful response featuresWhat it does: this candidate was stopped before scoring because the raw repeatability and instrument metadata needed to build it safely were missing.
PLNCALCE cell identifierIdentifier used in CALCE storage files to join capacity, SOC, temperature, storage period, and impedance records.
PredeclaredWritten down before scoringThe inputs, comparisons, splits, models, and pass rules were chosen before looking at the result being judged.
Prediction headOne model output branchA separate model or output branch responsible for one target, such as real EIS, imaginary EIS, or SOH.
Pulse resistanceResistance estimated from a current pulseVoltage change divided by pulse current over a fixed time window, used here as a short ageing-sensitive measurement.
q_0.90The 90th percentile absolute residualThe development error radius used to form the stated 90% prediction range.
Q_freshFresh reference capacityThe same cell's capacity before ageing.
Q_nowCurrent measured capacityThe capacity measured at the present ageing checkpoint.
R_10sResistance estimated from a 10-second pulseThe absolute voltage change over ten seconds divided by the typical pulse current.
r_kDimensionless ratio at frequency kThe current impedance Z_k divided by the fresh baseline B_k.
RADAR4KITKIT battery research datasetExternal validation check. Current frozen test workflow result does not support the CALB rule.
Reduced frequencySmaller fixed set of frequency featuresThe full spectrum is replaced by selected shared points and low-, middle-, and high-frequency summaries.
reduced_frequencyWhy the name: it uses fewer frequency featuresWhat it does: replaces the full spectrum with fixed low-, middle-, and high-frequency summaries plus selected shared points.
RepresentationThe numerical form given to a modelThe same measurements can be expressed as raw values, ratios, normalized changes, or smaller summaries before modeling.
RidgeRegularized linear regressionA simple linear model that discourages very large fitted weights and serves as a strong basic comparison.
RMSERoot Mean Squared ErrorA prediction-error score that gives extra weight to larger mistakes. Lower is better.
RPTReference Performance TestPeriodic characterization test. In CALB, HPPC and C/20 tests are RPT-like but not literally named RPT.
ss means the reference impedance scaleThe magnitude of the fresh 1 Hz impedance used to remove absolute cell-size differences.
Scale and shapeSeparate impedance size from curve patternOverall impedance magnitude is stored separately from the normalized spectral shape and its change.
scale_shapeWhy the name: scale and spectral shape are stored separatelyWhat it does: keeps overall impedance size apart from the normalized curve pattern.
SOCState of ChargeBattery charge level. Bad SOC alignment can make comparisons unfair.
SOHState of HealthBattery ageing or degradation state. The current CALB work does not validate SOH prediction.
T(x)The transformed feature vectorInput x after the frozen imputation and standardization steps.
TDMTime-Domain MeasurementTime-series voltage/current data used to fit relaxation behavior from pulses or dynamic tests.
UDDSUrban Dynamometer Driving ScheduleDynamic driving profile used in CALB drive-cycle tests.
Uncertainty rangeRange showing prediction uncertaintyAn interval around a prediction that shows how uncertain the model is. A useful range must be tested for coverage.
UntouchedFinal answers not used before scoringThe target answers were not used to select features, models, limits, or pass rules.
US06High-aggression supplemental driving scheduleDynamic driving profile used in CALB drive-cycle tests.
v5_referenceWhy the name: the unchanged Version 5 feature designWhat it does: acts as the control representation that every new Version 6 representation must beat.
WRidge coefficient matrixThe fitted linear weights that map X to Y.
WLTPWorldwide Harmonised Light Vehicles Test ProcedureDynamic driving profile used in CALB drive-cycle tests.
XInput feature matrixRows contain model inputs and columns contain the fixed representation features.
YTarget matrixThe true EIS or health values the model learns to predict.
ZZ means the current measured EIS spectrumThe aged or current impedance spectrum that the model is trying to reconstruct.
Z_hat_kA hat means predicted, so this is predicted Z at kThe model's reconstructed impedance value at frequency point k.
Z_kZ at frequency index kThe current measured impedance value at one frequency point k.
Zero-shotNo target-data calibrationThe model is tested on a new dataset without learning from any labelled examples from that dataset.
