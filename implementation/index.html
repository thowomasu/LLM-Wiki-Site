Implementation planVM / API / HPC

Practical pipeline plan

This page explains what should be built next in simple steps. It keeps the work realistic while VM access is still uncertain.

Step 1

Local demo first

Run a small API locally. The API accepts a job request and starts a small battery-data processing task.

Step 2

Job status endpoint

Add simple status states: submitted, running, finished, and failed. This proves the workflow before connecting real HPC.

Step 3

Replace local job with VM/HPC

When FAU VM access is ready, replace the local job command with the real server or scheduler command.

Dataset frame

The pipeline should start from matched TS/EIS/DRT data

The implementation should not start from a random file format. It should start from the research frame: find datasets where time-series cycling data can be matched to EIS spectra, then prepare those spectra for DRT analysis where quality allows.

What the demo must show
