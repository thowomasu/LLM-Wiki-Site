# GitHub Pages Site

This folder is the curated public site for the LLM Wiki research outputs.

Expected project URL after GitHub Pages is enabled:

`https://nayeemfaisal.github.io/LLM-Wiki-Site/`

Recommended GitHub Pages setting:

- Source: Deploy from a branch
- Branch: main
- Folder: `/(root)`

## Research ownership

This research workspace is maintained by **Nayeem Faisal**. It records dated
evidence, dataset-screening decisions, and reproducible pipeline notes for the
TS, EIS, and DRT study. Candidate datasets are kept separate from validated
matches so the public record is clear about what remains to be verified.

Do not publish the whole vault unless you have audited it for raw data, local
paths, unsupported claims, and private material.
