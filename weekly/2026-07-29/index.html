Weekly update29 July 2026Dataset intake

Focused dataset intake for the TS + EIS + DRT pipeline

This week adds a small, traceable shortlist. The work is an intake screen, not a validation result: each source must still pass a file-level matching check.

Research workspace maintained by Nayeem Faisal.

What was completed

Three sources were checked against the same rule

  • Does the source contain a time-domain side, such as current, voltage, charge-discharge, or cycling data?
  • Does it contain an EIS side with frequency and complex impedance information?
  • Can the two sides be joined by an honest shared key, such as a cell ID, test ID, SOC, temperature, or protocol?
  • Can the resulting EIS be used for DRT only after quality, residual, stability, and uncertainty checks?
Candidate shortlist

What the public records say

Highest priority

Samsung ICR18650-26J companion records

Evidence: the published SOC-estimation work links a raw current/voltage record and an EIS record for Samsung ICR18650-26J cells. The related EIS description reports four cells, repeated spectra, and SOC levels from 10% to 100%.

Why it fits: it is the closest new candidate to a TS + EIS bridge.

Open check: confirm matching cell IDs and SOC labels in the downloaded files before using it as a paired dataset.

Open EIS record · Open current/voltage record
Importer check

WO3 Li-ion electrode data

Evidence: the Zenodo record provides charge-discharge and EIS CSV files, plus a README and diffusion-coefficient table.

Why it fits: it is a small open source for testing CSV ingestion, impedance column detection, and DRT input validation.

Limit: it is a material-level half-cell experiment, so it is not a replacement for the main commercial full-cell study.

Open Zenodo record
Format check

Cycle + EIS + CV material data

Evidence: the Mendeley package states that it contains CV, EIS, cycle, and full battery data, under a CC BY 4.0 licence.

Why it fits: it provides a second independent format to test protocol metadata and raw impedance handling.

Limit: the source is materials-focused. It stays a format candidate until its files show reusable IDs and comparable test conditions.

Open Mendeley record
