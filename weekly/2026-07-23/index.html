Research finding

New direction: human-readable plus structured knowledge

The useful finding from the professor's OKF link is that the wiki can have two layers. The first layer is the website, written for humans. The second layer is structured Markdown with metadata, written so future tools can read the project more reliably.

This matters because the project has many kinds of material: datasets, validation notes, scripts, presentation pages, pipeline decisions, VM/HPC blockers, and weekly updates. A structured layer makes the work easier to audit, reuse, and extend.

New dataset screen · 23 July 2026

Five external datasets compared

  • Best full match: Cambridge uneven-usage EIS, with same-cell GCPL and GEIS records in the local manifest probe.
  • Strong candidates: NASA PCoE and CALCE, both with same-cell time-domain or capacity evidence plus impedance evidence.
  • Partial candidate: Battery Archive, because the public page shows cycling data but does not confirm an EIS match.
  • EIS control: the 54-cell Zenodo set has EIS and machine-readable metadata, but no time-series side.
  • Next: use a frozen cell-level holdout, reconstruction error, residual checks, and uncertainty before calling any source validation.
