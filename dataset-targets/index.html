Main research target TS + EIS + DRT Updated 2026-07-29

Dataset search and matching plan

Our main target is to find and improve battery datasets that connect time-series cycling data, EIS measurements, and DRT-ready impedance analysis. The goal is not only to collect more data, but to find datasets that can actually support the pipeline.

TStime-series cycling, current, voltage, temperature, capacity
EISfrequency, real impedance, imaginary impedance, test conditions
DRTimpedance data good enough for distribution-of-relaxation-time analysis
Simple research question

What are we looking for?

We are looking for datasets where the same cell or battery experiment has both normal cycling data and impedance data. The time-series data tells us how the cell behaves during charge and discharge. The EIS data tells us about internal electrochemical behavior. If the EIS quality is good enough, we can also use it for DRT analysis.

The best datasets are the ones where these parts can be matched together by cell ID, cycle number, state of charge, temperature, aging condition, or test date.

Dataset matching frame

How we rank datasets

Level Dataset condition Usefulness for us
Best match Time-series cycling data and EIS spectra exist for the same cells, with cycle/SOC/temperature labels. Can support TS to EIS modelling and later DRT analysis.
Good match EIS exists with aging labels, but time-series cycling data is incomplete or separate. Useful for DRT validation and EIS-based health analysis.
Partial match Strong cycling data exists, but EIS is missing or only available for a few checkpoints. Useful for pipeline testing, but weaker for DRT.
Low match Only summary capacity/SOH data exists without raw time-series or impedance spectra. Can be used as background evidence, not as the main pipeline dataset.

Five external datasets compared

  • Best full match: Cambridge uneven-usage EIS, with same-cell GCPL and GEIS records in the local manifest probe.
  • Strong candidates: NASA PCoE and CALCE, both with same-cell time-domain or capacity evidence plus impedance evidence.
  • Partial candidate: Battery Archive, because the public page shows cycling data but does not confirm an EIS match.
  • EIS control: the 54-cell Zenodo set has EIS and machine-readable metadata, but no time-series side.
  • Next: use a frozen cell-level holdout, reconstruction error, residual checks, and uncertainty before calling any source validation.

Pipeline impact

How this improves the research frame

  1. It gives us a clear rule for choosing datasets instead of collecting random battery data.
  2. It connects the dataset search directly to the model target: predicting or explaining EIS/DRT behavior from cycling data.
  3. It makes every new dataset easier to compare using the same TS/EIS/DRT matching score.
  4. It gives a clear weekly task: screen new sources, rank them, and add the best ones to the wiki.
