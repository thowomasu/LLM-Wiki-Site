API and HPC pipeline example

A compact local example for submitting a battery-data request to an API and processing it in a separate worker step.

Maintained by Nayeem Faisal

What is included

  • app.py: API entry point
  • worker.py: separate processing worker
  • sample_battery.csv: small input example
  • Run instructions and limitations

This is a reproducible local demonstration, not a live HPC deployment.
